自述

个人站点，非商业。

这是什么#

一个写字的地方，按三个领域组织：文学、哲学、计算机科学。以纯文本为主 —— 没有图片、没有公式、没有代码高亮。文字本身是目的。

目前有 8 篇文章、22 个标签。

这里没有什么#

没有广告、赞助、会员、付费墙、捐赠、推广链接；没有评论、点赞、分享、关注；不需要注册，没有推送；没有任何追踪分析，没有 A/B 测试，没有 SEO 营销。页面不加载第三方脚本，不请求外部字体。

怎么做的#

  • 用 Markdown 写作，用 Git 存档，静态生成后托管在 GitHub Pages 上。
  • 每个页面都有稳定的永久链接与一份从 Git 提交自动生成的修订记录。
  • 文章之间双向互链：你说到别人，别人页面上就会出现你；引用可以落到具体某一节，那一节里就会出现「本节被这些地方引用」。
  • 悬停站内互链会浮出目标那一篇的标题与摘要，片段在构建期就生成好，不发出任何请求。
  • 排版手法参考 gwern.net：元信息块、边注、可折叠章节、语义缩放、双向链接；但中文字距、行宽与边注规则是重新定的，不照搬拉丁版式。
  • 外观参考 chester.how：砖石网格、卡片尺寸、字体刻度与标签配色都照它的数值来。字体不下载，用系统字体栈 —— 字号与字距一致，字形由你的机器决定。

无障碍#

  • 语义化 HTML，每页只有一个一级标题，标题层级不跳级。
  • 对比度达标：正文 21.0:1、卡片正文 9.9:1、次要文字 4.3:1，都过 WCAG AA。全站只有一套亮色配色，因此只有一组数字需要守。
  • 键盘可达：折叠、链接预览、搜索、阅读模式都能只用键盘操作。
  • 关闭 JavaScript 后正文、脚注、目录、标签与互链仍然完整可读。唯一的例外是 404 页面的「是不是想找」—— 那一步需要脚本，无脚本时给出搜索与归档两条退路。
  • 尊重系统的「减弱动态效果」设置：动效只作用于导航与索引列表，正文里没有任何动画。
