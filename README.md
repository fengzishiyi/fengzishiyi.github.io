# NOVA · NHB 1430.2 的网页转译

一个单文件站点：把 **NASA Graphics Standards Manual（NHB 1430.2，1976）** 的版面规则原样搬成网页，并用两条参考片（一支游戏 PV、一支动画 UI 集）里取出的八个图版构件把版面组织起来。上线地址 <https://fengzishiyi.github.io/>。

## 三条硬性约束

1. **没有示例内容。** 站内每一句事实都能翻到出处：手册的章节与页码、实测的对比度数字、参考片的时间码。没有虚构作者、没有占位文章、没有「示例标题」。
2. **没有无用动效。** 没有入场动画、没有滚动揭示、没有线条生长、没有音效、没有换页淡入。留下的五件动效都回答「我在哪」，全部由内容状态驱动，不由时间驱动。
3. **底层严格照手册。** 两种专色、一个字体家族、12 栏网格、页码放外侧边距；红色只做状态记号。

## 五件功能性动效（06 节）

| 件 | 回答什么 | 实现 |
| --- | --- | --- |
| 进度条 + 节刻度 | 整页还剩多少 | 滚动只改一个 2px 填充宽度 |
| 运行头 | 我在哪一节 | `position:sticky`，不淡入 |
| 活动页码 | 5.14 的「页码放外侧」 | `IntersectionObserver` 跟踪每节 |
| 目录当前项 | 这一节里我到第几段 | 同上，当前项加一根红细线 |

## 文件

```
index.html                    站点本体：样式、七节内容、路由、五件功能性动效
404.html                      GitHub Pages 对未知路径的兜底页
.nojekyll                     关掉 Jekyll，静态文件原样发布
.github/workflows/pages.yml   把仓库根目录发布到 GitHub Pages
```

零依赖、零构建、零外部请求（字体、图标、统计、音视频都没有）。

## 改内容

- 七节正文在 `index.html` 的 `SECTIONS` 数组里，每节一条记录：`{ id, no, title, en, folio, brief, lede, cite, html }`。
- `html` 里的小节写 `<h2 id="…">1.3　标题</h2>`，**标题开头的编号就是页脚页码与目录编号的来源**；没有编号的小节不改变页码（沿用上一节）。
- 标本（色卡、字阶、十二栏、读数带…）由 `paintSpecimens()` 用 `data-*` 钩子生成，改数字只改那一处。
- 站点地址与描述在 `SITE`；页眉识别文字与页脚说明是静态 HTML。

## 已知取舍

- **URL 是 hash**，不是真实路径：搜索引擎只收一个地址。文章化需求的代价，这里换成规范站的形态。
- **关掉 JavaScript 只剩一行说明**：正文由脚本渲染。这是单文件的代价，写在 06 节里，不藏着。
- **中文没有 Helvetica**：回退到苹方 / 微软雅黑 Light / 思源黑体；「微软雅黑 Light」是独立家族名，不能靠 `font-weight:300` 选中。

## 发布

推到 `main` 分支。仓库设置里 Pages 若选「GitHub Actions」，`pages.yml` 会上传根目录；若选「从分支发布」，根目录的 `index.html` 会被直接发布。
