# NOVA · 设计、工程与太空

一个单文件个人博客：版式依据 **NASA Graphics Standards Manual（NHB 1430.2，1976）**——两种专色、一个字体家族、一张 12 栏网格；版面构件取自两条参考片（一支游戏 PV、一支动画 UI 集），每个构件都标了出处。上线地址 <https://fengzishiyi.github.io/>。

## 文件

```
index.html                    站点本体：样式、文章数据、路由、动效，全在一个文件里
404.html                      GitHub Pages 对未知路径的兜底页
.nojekyll                     关掉 Jekyll，静态文件原样发布
.github/workflows/pages.yml   把仓库根目录发布到 GitHub Pages
```

零依赖、零构建、零外部请求（字体、图标、统计、音视频都没有）。

## 路由

| 地址 | 页面 |
| --- | --- |
| `#/` | 文章（hero + 头条黑牌 + 五张索引卡 + 读数带） |
| `#/archive` | 归档，按年份分组 |
| `#/about` | 关于，信笺格式（3.1–3.3） |
| `#/standards` | 规范：色彩、字体、网格、字标、图版、动效，各配标本 |
| `#/post/<slug>` | 文章 |
| `#/post/<slug>/<小节 id>` | 文章里的某小节 |
| `#/standards/<小节 id>` | 规范页的某小节 |

按 `G` 显示 12 栏网格叠加层（带栏号），`S` 开关音效。系统里打开「减少动态效果」时，所有组装动效直接到位。

## 改内容

- **站点信息**：`index.html` 里的 `SITE`。
- **文章**：`POSTS` 数组，每条 `{ slug, no, cat, date, read, cover?, title, deck, body }`；`body` 里写 HTML，小节用 `<h2 id="anchor">标题</h2>`，侧栏目录自动由这些 `h2` 生成。
- **导航**：`NAV` 数组。
- **页眉/页脚**：静态 HTML。

## 动效

只有两种组装动作，都**只进不退**、出场一律硬切（换页不做淡入）：

| 动作 | 时长 | 出处 |
| --- | --- | --- |
| 细线生长（`scaleX` 0→1） | 340ms 线性 | UI 00:00:03 |
| 字被「排」出来（`clip-path` 从左揭开，组内递进） | 440ms，60–90ms 步进 | UI 00:00:04 |
| 红线＝当前（从左长出） | 220ms 线性 | PV 00:02:07 |

另外五件是**状态**而不是动画：进度条、运行头、活动页码、目录当前项、网格叠加层——它们由内容决定，不由时间决定。

不做：滚动揭示、位移与缩放、换页淡入、给插图配动效。

音效全部由 Web Audio 现场合成，没有音频文件，默认关闭，按 `S` 或页脚按钮打开。

## 已知取舍

- **URL 是 hash**，不是真实路径：搜索引擎只收一个地址，分享也只能指向首页。
- **关掉 JavaScript 只剩一行说明**：文章由脚本渲染，这是单文件的代价，写在 `<noscript>` 和 `/standards` 里。
- **中文没有 Helvetica**：回退到苹方 / 微软雅黑 Light / 思源黑体；「微软雅黑 Light」是独立家族名，不能靠 `font-weight:300` 选中。
- **参考片只取版面**：不取画面、不取音轨、不使用其中任何一帧。

## 发布

推到 `main` 分支。仓库设置里 Pages 若选「GitHub Actions」，`pages.yml` 会上传根目录；若选「从分支发布」，根目录的 `index.html` 会被直接发布。
